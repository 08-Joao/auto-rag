No Audi A6 2014 (C7), o controle de cruzeiro pode ser ativado a partir de **30 km/h**.

Isso vale tanto para:

- Cruise Control convencional: mínimo de 30 km/h.
- Adaptive Cruise Control (ACC): também permite definir a velocidade a partir de 30 km/h.

No ACC, inclusive, o manual informa que, se você apertar SET abaixo de 30 km/h, o sistema pode definir 30 km/h como velocidade mínima e acelerar até ela.

Fonte apresentada: Manuais de Carros Online.
